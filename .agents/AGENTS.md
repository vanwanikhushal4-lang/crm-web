# Project Rules

## Responsiveness
Every screen must be built to be extremely responsive. Ensure that all layouts gracefully collapse to single columns on mobile screens, and that navigation menus/sidebars are mobile-friendly (e.g., stacked or collapsible). Never use hardcoded widths without a max-width or flex fallback.

## Animations and Scrollability
Implement rich, dynamic micro-interactions throughout the project. 
1. Use a lot of CSS animations, transitions, and hover effects.
2. Ensure components like calendars, lists, and carousels feel smooth and highly scrollable.
3. Every UI element should feel "alive" (e.g., fading in, sliding in, smooth background transitions).
